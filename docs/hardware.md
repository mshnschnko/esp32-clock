# Оборудование

> Фактический парк оборудования с маркировками. Пункты с пометкой *(проверить)* подтверждаются
> на этапе проверки железа (I2C-сканер, тест экрана).

## Используется в проекте

### ESP32

| Параметр | Значение |
|---|---|
| Модуль | ESP32-WROOM-32 |
| Плата | 30-pin DevKit (тип DOIT DevKit V1) |
| USB-UART | CH340C |
| Разъём | USB-C (питание + прошивка) |
| PlatformIO board | `esp32dev` |
| I2C | SDA — GPIO21, SCL — GPIO22 (аппаратная шина по умолчанию) |
| Переключение режимов | GPIO32 — сенсорный канал T9 (провод), позже кнопка на тот же пин |

### Expansion board (плата расширения под 30-pin ESP32)

| Параметр | Значение |
|---|---|
| Вход DC | разъём DC, на плате указано 6.5–16 В |
| Вход USB | micro-USB и USB-C, 5 В (только питание) |
| Стабилизатор | AMS1117-5.0 (маркировка `AMS1117 50`), DC → 5 В |
| Диоды | 2 × SS24 (диоды Шоттки 2 А / 40 В) — развязка источников питания |
| Колодка питания | 8 пинов: 2 × 5 V, 2 × 3.3 V, 4 × GND |
| Ряды у GPIO | S (сигнал = GPIO), V (питание), G (GND) |

Заметки:
- Линия 3.3 В платы расширения, судя по всему, берётся с вывода 3V3 самой ESP32 (её собственный
  стабилизатор), т.к. на плате расширения стабилизатор только на 5 В. Подтверждено: при питании
  по USB-C самой ESP32 модули от колодки 3.3 В работают.
- Питание от USB-блока из розетки (любой мощности) безопасно: без USB PD всегда 5 В. Кабель USB-A → USB-C
  работает всегда; USB-C → USB-C может не дать питания, если на плате ESP32 нет резисторов CC.
- Напряжение рядов **V** выбирается перемычкой 3.3/5 В; сейчас перемычка стоит на **3.3 В**.
  Без мультиметра ряды V всё равно **не используем**, питание берём только с подписанных пинов колодки питания.
- AMS1117 — линейный стабилизатор: при 12 В на входе и токе 300 мА на нём рассеивается ≈ 2 Вт,
  он будет сильно греться. Для постоянной работы от DC лучше адаптер 7–9 В или питание 5 В
  через USB платы расширения. Решить при переходе на автономное питание.

### OLED-экран

| Параметр | Значение |
|---|---|
| Размер | 1.3", 128×64, монохромный |
| Маркировка шлейфа | GME12864-77 |
| Контроллер | **SH1106** — подтверждено тестовой картинкой (U8g2 `SH1106_128X64_NONAME_F_HW_I2C`) |
| Интерфейс | I2C |
| Порядок пинов | **GND, VCC, SCL, SDA** (GND первым!) |
| Выбор адреса | ADDRESS_SELECT 0x78 / 0x7A (8-битная запись) → 0x3C / 0x3D (7-битная); стоит **0x3C** — подтверждено сканером |
| Питание | 3.3 В (у таких модулей допускается 3.3–5 В, но используем 3.3 В) |

### Модуль RTC

| Параметр | Значение |
|---|---|
| Плата | HW-084 (клон ZS-042), длинный модуль с батарейным отсеком |
| Микросхема | DS3231SN (маркировка `DS3231SN 2407A4 215AB`) |
| EEPROM | AT24C32 на модуле |
| Пины | 32K, SQW, SCL, SDA, VCC, GND (32K и SQW не используются) |
| Адреса I2C | 0x68 (DS3231), 0x57 (EEPROM) — подтверждено сканером |
| Батарейка | CR2032 (неперезаряжаемая) |
| Питание | **только 3.3 В** |

Заметки:
- На модуле есть цепь подзарядки батарейки (резистор ≈ 200 Ом + диод 1N4148), рассчитанная на LIR2032.
  При питании 3.3 В и CR2032 (≈ 3 В) ток подзарядки практически отсутствует, поэтому пока работаем так.
- Батарейка проверена: после отключения USB время сохраняется и идёт (`lostPower() == false`).
- Встроенный датчик температуры: шаг 0.25 °C, точность ±3 °C, обновление раз в 64 с; меряет
  температуру кристалла, рядом с работающей ESP32 будет выше комнатной.
  **Никогда не подавать на модуль 5 В при установленной CR2032.**
- Правильное решение — выпаять резистор или диод цепи подзарядки (когда будет паяльник).

## Будущее расширение парка

| Компонент | Зачем |
|---|---|
| Мультиметр | Проверка напряжений на рядах V и выходах стабилизатора перед подключением 12 В |
| Паяльник | Отключение цепи подзарядки DS3231, пайка проводов к тумблеру и кнопкам |
| Тумблер ON-OFF-ON (есть, без проводов) | Переключение режимов отображения / выключатель |
