# Этапы разработки

> Требования — [idea.md](idea.md). Каждый этап: план (Plan mode) → код → проверка на железе → коммит.

## Сделано (первая версия)

| Этап | Содержание | Требования |
|---|---|---|
| 1 | Оборудование, подключение, проверка железа: I2C-сканер, экран SH1106, DS3231 с батарейкой | — |
| 2 | Wi-Fi с порталом настройки (WiFiManager), время по NTP, часовой пояс UTC+3, резерв в DS3231 | 3.1, 3.2, 3.4 |
| 3 | Цифровой и аналоговый режимы, переключение касанием (GPIO32), экран состояния | 3.3 |
| 4 | Погода MET Norway (Open-Meteo из домашней сети без VPN недоступен): экраны «сейчас», «по часам», «по дням»; значок и температура на улице на часовых экранах; загрузка в фоновой задаче раз в 30 мин | 6 (погода) |

## Следующие этапы

### Этап 5 — ночной режим
- По расписанию экран тускнеет или гаснет (OLED выгорает от статичной картинки, часы работают круглосуточно).
- Расписание — в `include/config.h` (до этапа 6).

### Этап 6 — веб-интерфейс настроек
- Страница настроек в браузере: часовой пояс, координаты для погоды, расписание ночного режима,
  режимы отображения, яркость.
- Настройки хранятся в NVS, константы из `config.h` становятся значениями по умолчанию.
