# esp32-clock

Настольные Wi-Fi часы на ESP32: время по NTP с резервом в RTC DS3231, OLED-экран 128×64
с цифровым и аналоговым режимами. Дальше — погода и другие данные.

Статус:
- **этап 1 завершён** — железо проверено (экран SH1106, DS3231 с батарейкой);
- **этап 2 завершён** — Wi-Fi с порталом настройки, время по NTP, часовой пояс UTC+3, резерв в DS3231;
- следующий этап — цифровой и аналоговый режимы отображения и их переключение.

## Сборка и прошивка
Нужны VS Code + расширение PlatformIO IDE и драйвер CH340.

```
pio run                  # сборка
pio run -t upload        # прошивка
pio device monitor       # лог (115200) и команды
```

## Первая настройка Wi-Fi
Пароль от домашней сети в прошивке не хранится — он вводится один раз с телефона.

1. Включить часы. Если сеть ещё не настроена (или сохранённая недоступна 15 с), на экране
   появится **Wi-Fi setup** с именем точки доступа и паролем.
2. Подключиться с телефона к сети **esp32-clock**, пароль — на экране (по умолчанию `clock-setup`).
3. Страница настройки откроется сама; если нет — открыть в браузере `192.168.4.1`.
4. **Configure WiFi** → выбрать домашнюю сеть (**только 2.4 ГГц**) → ввести пароль → **Save**.
5. Часы подключатся, получат время по NTP и запишут его в DS3231.

Пока портал открыт и к точке доступа никто не подключён, часы каждые 30 с пробуют
подключиться к сохранённой сети (например, если роутер включился позже часов). Портал
закрывается через 5 минут; часы продолжают идти по DS3231 и пытаются переподключиться каждые 30 с.

## Команды в мониторе порта
Набрать в `pio device monitor` и нажать Enter:

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `status` | состояние Wi-Fi, время, последняя синхронизация, память |
| `ntp` | синхронизировать время сейчас |
| `wifi reset` | забыть сохранённую сеть и перезагрузиться в портал настройки |
| `screen test` | тестовая картинка экрана на 5 с |

## Индикация на экране
- Слева сверху — уровень Wi-Fi (3 полоски); мигают — подключение; зачёркнуты — нет сети; `AP` — портал.
- Справа сверху — источник времени: `NTP` (синхронизировано), `RTC` (из DS3231),
  мигающий `RTC?` (время из DS3231, ещё ни разу не подтверждено по NTP), пусто — времени нет
  (на месте часов мигает `--:--`).
