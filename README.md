# esp32-clock

Настольные Wi-Fi часы на ESP32: время по NTP с резервом в RTC DS3231, OLED-экран 128×64
с цифровым и аналоговым режимами. Дальше — погода и другие данные.

Статус:
- **этап 1 завершён** — железо проверено (экран SH1106, DS3231 с батарейкой);
- **этап 2 завершён** — Wi-Fi с порталом настройки, время по NTP, часовой пояс UTC+3, резерв в DS3231;
- **этап 3 завершён** — цифровой и аналоговый режимы, переключение касанием, экран состояния;
- **этап 4 завершён** — погода (MET Norway): сейчас, по часам, по дням;
- дальше: **5 — циферблат как настройка и автовозврат на часы**, **6 — ночной режим**,
  **7 — веб-настройки** ([roadmap](docs/roadmap.md)).

## Режимы и управление
Провод на GPIO32 (пин S ряда D32 платы расширения) — сенсорная «кнопка», см. [подключение](docs/wiring.md).

| Действие | Результат |
|---|---|
| Короткое касание | следующий экран: часы → погода сейчас → по часам → по дням → часы |
| Удержание ~1 с на часах | сменить циферблат: цифровой ↔ аналоговый (запоминается) |
| Удержание ~1 с на погоде | экран состояния на 10 с (Wi-Fi, IP, синхронизация, погода, аптайм); касание закрывает |
| 15 с без касаний не на часах | автоматический возврат на часы (`kAutoReturnMs` в `config.h`) |

После включения всегда открываются часы с последним выбранным циферблатом.

Позже касание заменяется кнопкой одной строкой в `include/config.h` (`INPUT_SOURCE`).

## Погода
[MET Norway Locationforecast](https://api.met.no/weatherapi/locationforecast/2.0/documentation)
(норвежский метеоинститут, сервис Yr; без ключа, но с обязательным User-Agent — `kWeatherUserAgent`).
Санкт-Петербург — координаты `kWeatherLat/Lon` в `include/config.h`.
Обновление раз в 30 минут в фоновой задаче (часы не замирают); при ошибке — повтор через 1, 2, 4… мин.
Open-Meteo из домашней сети без VPN был недоступен.

- **Сейчас** — значок, температура, «ощущается» (расчётная, по формуле Стедмана), описание, ветер, влажность.
- **Next hours** — через 3, 6, 9, 12 ч: значок, температура, осадки за 3 ч (мм).
- **Forecast** — сегодня (оставшаяся часть дня) и 3 дня: значок, максимум/минимум, осадки за день (мм).
- На часовых экранах внизу — значок и температура на улице.
- В заголовке погодных экранов — давность данных (`5m`); старше 3 ч — с `!`.

## Сборка и прошивка
Нужны VS Code + расширение PlatformIO IDE и драйвер CH340.

```
pio run                  # сборка
pio run -t upload        # прошивка
pio device monitor       # лог (115200) и команды
```

## Первая настройка Wi-Fi
Пароль от домашней сети в прошивке не хранится — он вводится один раз с телефона.

1. Включить часы. Если сеть ещё не настроена (или сохранённая недоступна 15 с), на экране
   появится **Wi-Fi setup** с именем точки доступа и паролем.
2. Подключиться с телефона к сети **esp32-clock**, пароль — на экране (по умолчанию `clock-setup`).
3. Страница настройки откроется сама; если нет — открыть в браузере `192.168.4.1`.
4. **Configure WiFi** → выбрать домашнюю сеть (**только 2.4 ГГц**) → ввести пароль → **Save**.
5. Часы подключатся, получат время по NTP и запишут его в DS3231.

Пока портал открыт и к точке доступа никто не подключён, часы каждые 30 с пробуют
подключиться к сохранённой сети (например, если роутер включился позже часов). Портал
закрывается через 5 минут; часы продолжают идти по DS3231 и пытаются переподключиться каждые 30 с.

## Команды в мониторе порта
Набрать в `pio device monitor` и нажать Enter:

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `status` | состояние Wi-Fi, время, последняя синхронизация, память |
| `next` | как касание: следующий экран |
| `hold` | как удержание: на часах — сменить циферблат, на погоде — экран состояния |
| `face` | сменить циферблат (цифровой ↔ аналоговый) |
| `touch` | сырые показания сенсора (для подстройки порога) |
| `weather` | данные о погоде и последняя ошибка + запросить обновление |
| `ntp` | синхронизировать время сейчас |
| `wifi reset` | забыть сохранённую сеть и перезагрузиться в портал настройки |
| `screen test` | тестовая картинка экрана на 5 с |

## Индикация на экране
- Слева сверху — уровень Wi-Fi (3 полоски); мигают — подключение; зачёркнуты — нет сети; `AP` — портал.
- Справа сверху — источник времени: `NTP` (синхронизировано), `RTC` (из DS3231),
  мигающий `RTC?` (время из DS3231, ещё ни разу не подтверждено по NTP), пусто — времени нет
  (на месте часов мигает `--:--`).
